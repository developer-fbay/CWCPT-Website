# Agents: read this first

Co Work Cape Town website rebuild (Nuxt 4, Cloudflare Workers, n8n, Supabase if needed).

1. If a `_context/` folder exists in the project root, read `_context/README.md` before doing anything.
   It holds the full brief, design system, page plans, decisions and open questions.
   It is git-ignored on purpose: never commit it, never copy its contents into tracked files.
2. Then read `PLAN.md` (decisions and build order) and `README.md` (how to run, folders, rules).

Key rules: British English, no em dashes; prices in £ first with the rand figure beside them as the approved copy gives
it (other currencies only through the Pricing display switch, at a confirmed, dated rate);
never invent prices, sizes, terms or ratings (leave `[brackets]`);
review and FAQ text word for word; members use "tags", not "access cards"; colours and glows only from tokens;
content only in `app/data`; work on branch `jesse` and open PRs into `main`.
